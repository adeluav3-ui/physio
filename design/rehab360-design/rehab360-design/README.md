# Rehab360 design reference

Source of truth for every screen. Open `reference/*.dc.html` for exact markup and CSS; compare with `screenshots/*.png`. Tokens: `tokens.css`. Brand rules: `BRAND.md`. Logos: `brand-assets/`.

Care-flow screens added in November 2026:
- ConsultRoom: professional video room (patient summary, call, Notes / Exercises / Plan / Refer tabs)
- ConsultChat: professional chat consultation, Notes tab
- NoteSignoff: session note, outcome measures, next step, patient summary, sign-off
- Availability: weekly hours, days off, session settings
- ChoosePhysio: patient phone, ONE full ranked list of physiotherapists with filters (no top-three)
